# P3.0-S Gate 3 Failure Debug Report

> 日期：2026-09-08
> 范围：Gate 3 真实 YCB-V 数据 10/10 失败的系统性定位
> 约束：不改模型、不重训练、不调参、不改实验设计；仅定位故障层

---

## A. 目标

Gate 3 在 10 帧真实 YCB-V 数据上 0/10 失败（bottle 0/5, bowl 0/5）。
本报告逐层（D1–D6）定位失败发生在管线中的哪个环节、什么机制。

## B. 审计范围与约束

| 允许 | 禁止 |
|------|------|
| 读取中间变量、统计数据 | 修改模型/网络/训练 |
| 对比合成 vs 真实中间量 | 重新训练或微调 |
| 计算 GT 对照指标 | 调整 RANSAC/ICP 参数 |
| 定位故障层与机制 | 改变实验定义 |

## C. 管线层级（审计点）

```
D1: 真实输入（RGB-D + mask + K + depth_scale）
D2: 反投影 + 体素下采样 + 随机采样 + 归一化
D3: CoordNet 前向 → 预测 canonical 坐标
D4: RANSAC-Umeyama → 初始位姿
D5: ICP 精修 → 最终位姿
D6: 合成 vs 真实全链路对比
```

## D. 方法

新增 `scripts/_debug_gate3.py`，在 Gate 3 管线基础上增加以下诊断：

1. **GT canonical 坐标**：`gt_canonical = T_model_cam @ cam_xyz`（用 GT pose 反算每个采样点的模型系坐标）
2. **逐点 canonical 误差**：`||pred_canonical - gt_canonical||`
3. **逐轴相关性**：pred vs gt canonical 各轴的 Pearson r，以及 pred vs -gt（检测轴翻转）
4. **归一化参数对比**：合成训练数据 vs 真实帧的 center/scale 分布
5. **ICP 增量**：ICP 输出 vs RANSAC 输出的旋转/平移差
6. **合成验证基线**：10 个 Gate 2 val 样本的全链路统计

## E. 逐层审计结果

### D1: 真实输入审计 — **PASS（无异常）**

| 检查项 | 结果 |
|--------|------|
| RGB shape/dtype | (480,640,3) uint8, 范围 [0,255] |
| Depth 物理范围 | 0.71–3.73m（合理） |
| depth_scale | 全部 0.1（一致） |
| K 矩阵 | 全部 [1066.78, 0, 312.99; 0, 1067.49, 241.31; 0,0,1] |
| mask_visib | 15510–24733 px（合理） |
| visib_fract | 0.981–1.000（几乎全可见） |

**结论**：原始数据加载、单位转换、mask 读取均无异常。

### D2: 反投影 + 归一化 — **FAIL（归一化尺度污染）**

#### 关键发现：depth 离群点使 normalize_points 尺度膨胀

`normalize_points` 使用 `scale = max(||xyz - centroid||)`，对单个极端离群点极度敏感。

| 帧 | cam_sampled 半径(m) | norm scale(m) | 备注 |
|----|---------------------|---------------|------|
| **合成 val（训练分布）** | **0.101–0.122** | **0.101–0.122** | 网络训练时见过的范围 |
| obj05/000620 | 0.121 | 0.121 | 正常（勉强在训练分布边缘） |
| obj05/000653 | 0.126 | 0.125 | 略超 |
| **obj05/000721** | **2.466** | **2.466** | **depth 离群：z_max=3.196m（物体在 0.8m）** |
| obj05/001044 | 0.136 | 0.136 | 略超 |
| obj05/001113 | 0.118 | 0.118 | 正常 |
| obj13/000001 | 1.000 | 1.000 | bowl 边缘 depth 噪声 |
| obj13/000093 | 1.082 | 1.082 | 同上 |
| obj13/000138 | 1.111 | 1.111 | 同上 |
| obj13/000162 | 1.168 | 1.168 | 同上 |
| obj13/000247 | 1.188 | 1.188 | 同上 |

**帧 721 具体机制**：
- 反投影 XYZ 范围：x=[0.13, **0.63**], y=[**-0.37**, 0.10], z=[0.77, **3.20**]
- 其他 bottle 帧典型范围：x=[0.06, 0.19], y=[-0.11, 0.10], z=[0.70, 1.02]
- mask 存在 depth 边缘泄漏或 sensor 噪声，导致 ~3m 处出现背景点
- 单个 3.2m 离群点 → scale=2.47m → 物体所有点被压缩到 norm_xyz ∈ [-0.01, 0.19]
- 网络训练时见过的 norm_xyz std 为 [0.20, 0.40, 0.25]；此帧输入 std 为 [0.01, 0.02, 0.04]
- **输入完全偏离训练分布 → 预测无意义**

**Bowl 帧机制**（scale 1.0–1.2m）：
- bowl 直径 162mm，但深度噪声在碗边缘产生 0.5–1.2m 的离群点
- 归一化尺度比训练分布大 10× → 输入被压缩到 norm_xyz std [0.02–0.04, 0.02–0.03, 0.04–0.11]
- 同样严重偏离训练分布

**即使"干净"bottle 帧**（scale 0.118–0.136m）：
- 训练分布上界 ~0.122m，这些帧在训练分布边缘或之外
- 输入 std 对比：合成 [0.20, 0.40, 0.25] vs 真实干净帧 [0.11–0.15, 0.35–0.42, 0.15–0.21]
- X 轴 std 偏低（0.11 vs 0.20），说明 bottle 在相机前方横向展布较小

#### 归一化尺度汇总

| 统计 | 合成 val | 真实（全部 10 帧） |
|------|----------|-------------------|
| mean scale | 0.109m | 0.851m |
| std scale | 0.005m | 0.712m |
| min scale | 0.101m | 0.118m |
| max scale | 0.122m | 2.466m |

**D2 结论**：归一化尺度污染是 Gate 3 失败的**主要直接原因**。10 帧中 6 帧（帧 721 + 全部 5 帧 bowl）尺度偏离训练分布 10–20×；其余 4 帧在训练分布边缘。

**即使最干净的 bottle 帧（000620/000653/001044/001113），逐点 canonical 误差仍为 97–106mm —— 约物体直径的 50–54%。**

#### 逐轴结构分析（干净 bottle 帧）

| 轴 | pred mean | gt mean | Pearson r | -r |
|----|-----------|---------|-----------|-----|
| X | +0.007~+0.010 | -0.015~-0.027 | **-0.78 ~ -0.94** | 0.78~0.94 |
| Y | +0.015~+0.016 | +0.019~+0.022 | +0.45~+0.75 | -0.45~-0.75 |
| Z | -0.022~-0.027 | -0.000~+0.005 | **-0.996~-0.999** | 0.996~0.999 |

**解读**：
- **X 轴**：强负相关（r ≈ -0.8~0.94）→ 网络预测的 X 方向与 GT 相反
- **Z 轴**：极强负相关（r ≈ -0.997）→ 网络预测的 Z 方向与 GT 几乎完美翻转
- **Y 轴**：中等正相关（r ≈ +0.5~0.75）→ 部分正确但弱

这说明网络的预测**存在结构**（不是随机噪声），但存在系统性轴翻转/缩放/偏移。

#### 预测 vs GT 尺度对比（干净 bottle 帧）

| 统计 | pred canonical | gt canonical |
|------|---------------|--------------|
| centroid radius | 0.084–0.096m | 0.118–0.136m |
| X range | ~[-0.02, +0.03] | ~[-0.05, +0.07] |
| Z range | ~[-0.12, +0.07] | ~[-0.09, +0.10] |
| X std | 0.011–0.015 | — |
| Z std | 0.041–0.051 | — |

**预测的 canonical 坐标比 GT 压缩 ~20–30%，且 centroid 偏移。** 这是回归网络常见的 mean-seeking 退化（训练损失最小化策略导致预测趋向条件均值）。

**D3 结论**：
1. 归一化污染帧（帧 721 + bowl）：输入偏离训练分布 → 预测无意义
2. 干净帧：预测有结构但误差 ~100mm（≈ 0.5d），远超 0.1d 阈值（19.65mm）
3. 系统性模式：轴翻转 + 尺度压缩 + centroid 偏移

|----|--------|--------|------------|---------------------|--------|
| obj05/000620 | 750 | 73.2% | 5.7 | 116.5 | 177.3 |

| obj13/000093 | 32 | 3.1% | 6.8 | 124.8 | 158.3 |

| obj13/000162 | 34 | 3.3% | 6.5 | 112.6 | 164.8 |
| obj13/000247 | 36 | 3.5% | 6.3 | 120.6 | 158.8 |

**分析**：
- 干净 bottle 帧 RANSAC 内比率 30–73%，内残差 ~6mm → RANSAC **能**在 pred↔cam 之间找到一致的刚性变换
- 但旋转误差全部 ~170–180° → 找到的刚性变换对应的位姿与 GT 相差约 180° 旋转
- Bowl 帧内比率 2.5–3.5% → 归一化污染导致对应关系近乎随机

**RANSAC 在干净帧上为什么内比率还不错但位姿仍然错？**
- 预测 canonical 有结构（轴相关 |r| > 0.75），所以存在一个刚性变换能对齐大部分点
- 但逐点误差 ~100mm 意味着对齐后仍有大量残差
- RANSAC 阈值 10mm 只能接受误差较小的子集为内点
- 最终位姿由内点拟合，但内点的几何分布不足以约束 6-DOF 位姿到 < 0.1d

**D4 结论**：RANSAC 本身工作正常（在干净帧上找到高内比率的一致对应）。瓶颈在 D3——对应关系精度不足以产生正确位姿。

## F. 故障定位总结

### 确认事实（Confirmed Facts）

1. **管线代码无 bug**。坐标变换审计（`_audit_coordinate_transform.py`）闭环验证通过：合成数据 4.05° 旋转 / 4.1mm 平移 / 97.2% 内点。

2. **归一化尺度污染是主要直接故障**。`normalize_points` 的 max-radius 对 depth 离群点极度敏感：
   - 帧 721：单个 z=3.2m 离群点 → scale=2.47m（训练上界 0.122m 的 **20×**）
   - Bowl 帧：碗边缘 depth 噪声 → scale=1.0–1.2m（训练上界的 **10×**）
   - 归一化后输入被压缩到训练分布的 5–20% → 网络输出无意义

3. **即使归一化正常的帧，canonical 预测仍 ~100mm 误差**。最干净的 bottle 帧（scale 0.118–0.136m）逐点 ‖pred - gt_canonical‖ = 97–106mm ≈ 0.5d。预测有结构（轴相关 |r| = 0.75–0.99）但存在系统性尺度压缩（~20%）和 centroid 偏移。

4. **RANSAC 和 ICP 不是独立故障点**。RANSAC 在干净帧上找到高内比率的一致对应（证明对应关系有结构），但精度不足以约束正确位姿。ICP 无法纠正大偏差。

### 强证据推断（Strong Evidence）

5. **Gate 3 失败的充分原因链**：
   ```
   depth 离群点（mask 边缘泄漏 / sensor 噪声）
     → normalize_points max-radius 尺度膨胀（10–20×）
       → CoordNet 输入偏离训练分布
         → canonical 预测误差 ~100mm（0.5d）
           → RANSAC 位姿误差 ~170–180°
             → ICP 无法纠正
               → ADD ~117mm >> 0.1d 阈值
   ```

6. **即使修复归一化（如用 percentile 替代 max），canonical 预测 ~100mm 误差仍然存在**。这是网络容量/训练数据/域差的综合结果，不是归一化能单独解决的。

### 假设（Hypotheses，需进一步验证）

7. **H1**：bottle 的 depth 离群点来自 mask_visib 边缘的深度传感器噪声（飞行深度相机在物体边缘的已知问题）。可通过 mask 腐蚀（erode 2–3 px）验证。

8. **H2**：bowl 的 depth 离群点来自碗内壁/外壁的多次反射（bowl 几何导致深度跳变）。

9. **H3**：CoordNet 的 canonical 预测退化（尺度压缩 + centroid 偏移）是因为训练损失在相机系计算（`‖T@pred - xyz_cam‖`），对 canonical 空间的尺度/偏移无直接约束。

## G. 与"sim-to-real domain gap"的关系

"Domain gap" 是正确的顶层归因，但不够精确。本报告将其分解为三个具体机制：

| 机制 | 影响帧 | 严重度 | 可修复性 |
|------|--------|--------|----------|
| **归一化尺度污染**（depth 离群 → max-radius 膨胀） | 帧 721 + 全部 bowl（6/10） | **致命** | 工程可修（percentile/robust scale/mask 腐蚀） |
| **归一化尺度边界偏移**（干净帧仍在训练分布边缘） | 干净 bottle（4/10） | 中等 | 需训练数据增强或域适应 |
| **Canonical 预测精度不足**（~100mm ≈ 0.5d） | 全部帧 | **致命** | 需更大网络/更多训练/域适应/损失函数改进 |

## H. 后续实验建议（不在本次范围内）

以下仅为故障定位的自然延伸，**不在本次 debug 约束范围内**，需单独批准后执行：

1. **验证 H1/H2（归一化修复）**：
   - 将 `normalize_points` 的 scale 改为 percentile-based（如 p99 或 p95）
   - 或 mask 腐蚀 2–3 px 后再反投影
   - 预期：消除 6/10 帧的致命尺度污染，观察干净帧 ADD 是否改善

2. **量化 canonical 预测精度上限**：
   - 用 GT canonical 替代 CoordNet 预测 → RANSAC → ICP → 评估
   - 预期：如果 GT canonical → ADD < 0.1d，则瓶颈确认在 D3（网络预测精度）
   - 如果 GT canonical → ADD 仍 > 0.1d，则管线有其他问题

3. **网络改进方向**（需独立提案）：
   - 增加网络容量（当前 ~59K 参数可能不足）
   - 在 canonical 空间增加直接损失项（当前仅相机系 L2）
   - 域适应（合成→真实的颜色/几何增强）
   - 鲁棒归一化（percentile / learned normalization）
